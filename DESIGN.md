# JackMeds · Functional Specimen

An independent software lab. The first impression should be that unusual ideas have become real, usable products.

## Visual grammar

- Use a small original JM mark as the author signature. Each product retains its own identity.
- Offset composition: text occupies the left two-thirds; a function-derived specimen occupies the right.
- Do not display project sequence numbers, including background watermarks. Projects can be reordered without changing their artwork. Identity comes from the name, color and functional motif.
- Use fine rules, squared geometry and generous empty space. Screenshots supply proof.
- Light: paper #F6F7F2, ink #171A1F, readable secondary #59616B, rule #CDD1CA.
- Dark: paper #0F1217, ink #EDF0F5, readable secondary #A6AFBD, rule #363D46.
- Account blue: #2E5BFF on light, #91ACFF on dark.
- Flowloud: #007E87 / #69D7DB, sentence-to-waveform motif.
- MingXu: #BA4238 / #F2A193, calculated chart structure.
- BiliDigest: #B83B69 / #F199B6, source-to-document pipeline.
- Kehua Garden: #4D733E / #A9C88F, layered memories and timeline.

## Typography and exports

Instrument Sans handles Latin display text; Source Han Sans SC handles Chinese; IBM Plex Mono handles metadata labels. Fonts are kept centrally with upstream licenses. All published SVG lettering is outlined; viewers need no fonts or external assets.

Hero: 1200 × 360, light and dark. Social preview: 1280 × 640 PNG, below 1 MB. Avatar: original JM mark at 512 × 512. Main name and value remain readable in Markdown independently of pictures.

The README uses native GitHub typography and rendering. Source images adapt through picture/source markup. Do not style the README with unsupported CSS or bake links/buttons into images.

## Content contract

Project name and value → real entrypoint → real product proof → capabilities → quick start → limits and privacy → development/docs. Up to four factual badges, and none when they do not help.

Product screenshots contain only fictional example records. Every pilot supplies docs/brand-proof.md with capture provenance. A diagram is labeled as a diagram, never represented as a working interface.

Profile is concise bilingual. Flowloud is Chinese with a separate English README. MingXu keeps English main and separate Chinese. BiliDigest keeps its existing language paths. Kehua Garden and historical projects use Chinese plus a short English summary.

The profile combines a restrained static identity header with API-backed project cards. Show when data was fetched, keep a native text alternative, use the same light/dark palette, and do not describe scheduled snapshots as real-time. Failed refreshes retain the previous successful snapshot. Project sequence numbers were removed following the owner's review.
